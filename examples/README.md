# cms-lab examples

These examples are small public projects for learning how cms-lab config,
scans, and reports behave.

## Run in StackBlitz

The links below open the GitHub example folders directly. The repository stays
the source of truth, so docs and examples can be reviewed together.

| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `next-prismic`        | [Run in StackBlitz](https://stackblitz.com/fork/github/i-afaqrashid/cms-lab/tree/main/examples/next-prismic?title=cms-lab%20Next%20Prismic%20config)        |

## Local examples

- `broken-prismic-demo`: no-secret demo that intentionally produces useful
  route, field, SEO, and image diagnostics against a public Prismic starter.
- `next-prismic`: compact config reference for copying cms-lab into an existing
  Next.js + Prismic App Router project.

Run commands from each example folder unless the README says otherwise.
