Suggested fix

CMS-ROUTE-404 · /uses

cms-lab found a published page document with uid uses but no route segment matched it. Most often this means the doc was added in the CMS without a corresponding entry in your routes config, or the Next.js dynamic segment isn’t generating this slug. 

// cms-lab.config.ts
routes: [
  { type: 'page', pattern: '/:uid', getPath: (d) => `/${d.uid}` },
+ { type: 'page', pattern: '/uses', getPath: () => '/uses' },
]

Or, more likely: add the slug to generateStaticParams() in app/[uid]/page.tsx.
